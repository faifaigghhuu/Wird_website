موقع وِرد | WIRD

محتويات الحزمة:
- index.html: الصفحة الرئيسية وبنية الموقع.
- style.css: التصميم والألوان وتنسيق شاشة الجوال.
- app.js: التنقل، القرآن، الأذكار، والمسبحة الرقمية.

طريقة التشغيل:
1) فك ضغط ملف wird_site_all_files.zip.
2) اترك الملفات الأربعة في المجلد نفسه.
3) افتح index.html باستخدام Safari أو متصفح حديث.
4) يحتاج تحميل نص القرآن والتلاوة إلى اتصال بالإنترنت.

ملاحظة: بعض معاينات الملفات داخل التطبيقات تمنع JavaScript؛ إذا الأزرار ما استجابت، افتح index.html في Safari بدل معاينة الملف.
